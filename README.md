# Sugar Crash Simulator — 网页原型

## 在 PyCharm 中运行
1. 运行本脚本，会在当前文件夹生成 `sugar_crash_simulator` 文件夹
2. 打开文件夹，直接双击 `index.html` 浏览器打开；也可以 PyCharm 右键 html → Open in Browser
3. 不需要 Python 包，不需要服务器

## 当前包含
- 奶白与奶茶棕响应式页面
- 中文 / English 切换
- 饮品预设、容量、饮用时间、目标睡觉时间
- 理论咖啡因残留估算与 SVG 曲线
- 糖分宽范围示例估算
- 个性化咖啡因敏感度选项
- 营养标签图片本地预览
- 时间线、规则模板生成的 AI 风格旁白、替代建议
- 科学限制与隐私免责声明

## 重要限制
- 当前是纯前端演示。所谓“AI 风格旁白”是规则模板，不是真正的生成式 AI。
- 营养数字是宽范围示例，不是品牌实测值。请勿把它当成营养标签或医疗建议。
- 图片只在浏览器本地预览，没有 OCR 识别，也没有上传服务器。
- 咖啡因半衰期模型是简化模型，不能预测个人几点入睡。
